# 世界与角色状态

世界状态卡在游戏左侧的小队下方，点击标题可以折叠。点击聊天右上角的按钮可以展开自己的角色面板，点击小队成员也能查看角色卡。

## 查看当前状态

卡片可能展示生命、行装、位置、任务、战斗或其他信息，具体显示什么由模组决定，会随着主持保存的状态更新。

想移动、分队或处理某种状态效果，在聊天中说出想做的事，让主持裁定。没有显示某个敌人或危险，不代表附近安全。

## 模组没有配置世界卡

没有世界卡也能正常游玩。可以打开「模组设定」查阅公开资料，或向主持询问当前情况。

## 结束冒险

冒险结束后，可以回看聊天和资料，不能再提交行动。也可以在「冒险设置 → 模组与存档」手动结束。

在「历史冒险」中可以回看或重新开启这局。重新开启会保留原有进度，想从头重玩则需要新建冒险。

删除冒险会永久移除这一局。需要留存时，先按[备份方法](../reference/faq.md#存档在哪里怎样备份)复制完整存档。
