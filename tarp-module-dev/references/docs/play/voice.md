# 语音朗读

语音朗读会把生成的文字读出来，玩家仍通过文字输入行动。目前支持小米 MiMo 的基础 TTS 和 VoiceDesign，需要单独填写 MiMo 按量付费 API Key，不会沿用聊天模型的密钥。

## 先连接，再试听

1. 在「设置 → 语音供应商」填写 MiMo API Key，点击「连接」。
2. 在「设置 → 冒险默认设置 → 语音」开启「允许语音」，选择模型和声音。
3. 使用基础 TTS 时选择预置音色；使用 VoiceDesign 时填写音色描述，例如“中年女性，声线低，说话干脆”。按需填写讲述风格，再点击「试听默认声音」。
4. 想自动播放新剧情，开启「自动朗读新消息」。

这些默认值只影响新冒险。已有冒险在「冒险设置 → 语音朗读 → 冒险语音配置」中单独调整。

需要朗读的文字会发送给语音服务，消耗你的服务额度。当前不支持配置 Token Plan 专属端点。

## 在聊天中播放和停止

鼠标移到消息上，点击「朗读此段」播放；再次点击可停止。玩家消息和历史消息也可以手动朗读。

点击输入区的扬声器按钮，可以开关这局的自动朗读。开启后，新完成的主持旁白、NPC 台词、队友回复和预写剧情会依次播放；不会自动重播历史记录，也不播报掷骰卡和工具结果。

播放时点击旁边的停止按钮，会停止当前声音和待播内容。手动朗读或试听时，会换成你选择的内容；离开冒险会停止播放。

## 当前冒险的语音开关

在「冒险设置 → 语音朗读 → 冒险语音配置」中关闭「允许语音」，会停止本局播放并禁用朗读，原有的声音设置会保留。

看不到扬声器或朗读按钮时，检查本局是否允许语音，以及所选语音供应商是否已连接。

## 给主持和队友换声音

### 主持人声音

在「冒险设置 → 语音朗读 → 主持人声音」点击「设置声音」或「修改声音」，选择声音、试听，再点「保存覆盖」。点击「恢复模组预设」清除本局覆盖。

### 队友声音

在「冒险设置 → 冒险小队 → 队友设置 → 声音」中试听，满意后点击「保存声音」。使用 VoiceDesign 时，音色描述不能为空；点击「恢复模组设定」可以取消自己的声音设置。

主持会优先使用你为这局设置的声音，其次是模组预设，最后是本局默认声音。队友会优先使用个人设置，其次是模组预设、入队时模板中的备用声音，最后才是本局默认声音。模组只预设了部分声音要求时，其余设置沿用备用配置。NPC 使用模组预设，没有预设时使用本局默认声音。

修改只影响这局之后合成的语音，不会改变角色性格或模组原件。

## 有文字却没声音

1. 检查本局是否允许语音、当前供应商是否已连接，再试「试听默认声音」。
2. 使用 VoiceDesign 时，检查音色描述是否为空；这种模式可能需要多等一会儿。
3. 自动朗读要等文字回复完成；想听旧消息，手动点击「朗读此段」。

失败时根据错误提示检查连接，再重试朗读。语音失败不会中断文字聊天。删除供应商连接后，使用这个供应商的冒险需要重新连接才能朗读。
