# 冒险笔记

点击游戏左侧的「笔记」，在「我的笔记」里直接写。关闭对话框即可继续聊天，再次打开会保留内容和滚动位置。

笔记只有自己能看，不会自动作为行动交给主持。想让主持回应，回到聊天中发送。

## 随手记录

可以把已确认的事实、猜测和下一步分开写，例如：

```text
已确认：店主说，灰衣人昨晚来取过货。
待核实：车辙是谁留下的？
下一步：去渡口问守夜人，暂时不碰仓库门锁。
```

笔记是纯文本，不提供 Markdown 预览，最多 20 万个字符。每名玩家在每段冒险中都有一份独立笔记，改昵称也不会丢。

## 看一眼保存状态

停止输入片刻后会自动保存，不用另点按钮。退出前等状态变成「已保存」。

显示「保存失败」时，点击「重试保存」；持续失败时先把文字复制到别处。应用会尽量在本机保留未保存的草稿，下次进入同一冒险时恢复。不过，草稿不能代替备份。

显示「笔记读取失败」时，点击「重试」。

## 笔记保存在哪里

笔记随当前冒险保存在本机。备份时复制整份冒险存档，位置与操作见[常见问题](../reference/faq.md#存档在哪里怎样备份)。
