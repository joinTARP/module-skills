# AI 主持

你用文字说出角色想做什么，主持会查阅模组资料，描述人物的反应和行动的后果。需要检定时，主持会发起掷骰，等结果出来后继续。

## 开始前要准备什么

1. [连接模型服务](../getting-started/models.md)，为当前冒险选择模型。
2. 完成选角或建卡，等开场讲完。
3. 在输入区选择「行动」，写下想做的事并发送。

如果提示没有可用模型，到「冒险设置 → 模型与主持 → AI 模型」选一个。完整开局步骤见[第一次冒险](../getting-started/first-adventure.md)。

## 把想做的事说清楚

动作、台词和问题可以写在同一条消息里，不需要固定格式。例如：

> 我蹲下来检查门锁，看看有没有撬动过的痕迹。先不碰锁，也不推门。

想和场景里的 NPC 说话，也用「行动」发送：

> 我把收据递给店主：「昨天晚上，来取货的人是不是穿着灰色外套？」

回复会逐步显示。向上翻阅时，聊天会暂停自动滚动，点击「回到最新」或「有新消息」就能继续跟随。鼠标停在资料名称上可以预览，点击可以查看详情；图片可以点击放大。点击玩家或队友的头像可以查看角色卡。

主持可能误解规则或遗漏事实。看到不一致时，指出具体条目，请它重新核对。

## 聊天和行动模式

| 模式 | 用途                                               |
| ---- | -------------------------------------------------- |
| 行动 | 让主持处理动作、台词和后果，行动消息旁有旗帜图标。 |
| 聊天 | 讨论或留句话；没有点名时，不立即调用 AI。          |

点击输入区的模式按钮，或按 Shift+Tab 切换；Shift+Enter 换行。

输入 `@`，从候选中选中主持或 AI 队友，就能让它回应。只手打 `@名字` 不会点名。选中点名对象后，整条消息会自动作为聊天发送；需要主持裁定行动时，另发一条不带点名的行动。队友正在回复时，点名聊天会排队等待。

### 和主持人聊天

想询问规则、澄清描述或沟通节奏时，从 `@` 候选中选择「主持人」：

> @主持人 刚才说的出口在哪边？

主持会解释，但不掷骰或推进剧情。需要开门、移动或向 NPC 发言时，使用不带点名的行动。

## 先讨论，再点「继续」

输入区右侧可以选择提交方式：

| 提交方式         | 发送后会发生什么                                         |
| ---------------- | -------------------------------------------------------- |
| 自动提交（默认） | 行动自动交给主持；积极或活跃队友可能先补充自己的行动。   |
| 手动提交         | 行动标为「待提交给主持人」，点击「继续」后一起交给主持。 |

想先商量计划，可以切到手动提交，用聊天讨论，再发送完整行动并点「继续」。

每人只保留最新一条待提交行动。再发新行动时，旧行动自动改为聊天；普通聊天和点名不替换已有行动。暂时不想行动，可以点击待提交消息旁的「改为聊天」。已经开始提交的行动不能这样撤回，想调整时需要另发消息。

## 生成中补充行动

在「冒险设置 → 对话与上下文」开启「主持插话」，就能在主持回复时补充行动。写好后按 Enter，或点击停止按钮左侧的发送箭头。

插话会先显示在输入框上方，等主持完成当前回应和掷骰等操作后再接收。主持尚未接收时，可以删除插话。每人最多 2 条，本局合计最多 5 条，每条最多 4000 字符。

需要立即改变方向时，点击「直接打断并提交」。它会停止当前生成，把队列里的插话交给主持；已经保存的变化不会撤销。停止生成或生成失败后，如果队列里还有内容，需要点击「提交给主持」。

## 回复中断后怎么办

短暂网络故障会自动重试。持续显示失败时，先检查[模型连接](../getting-started/models.md#没有回复时先看什么)，再根据提示处理：

- **发送没有确认**：点击「重试发送」。重试同一次发送不会重复添加消息。
- **回复生成失败或已停止**：先看已有文字和当前状态，再发一条新消息继续。
- **开场没完成**：点击「继续开场」。
- **等待你掷骰**：处理聊天里的[掷骰卡片](dice.md)。

点击「停止生成」会停止当前回复，并取消排队中的回应。已有文字和保存的状态会保留。未完成的掷骰会失效，已完成的结果保留。如果错误提示只保存了部分变化，先让主持核对状态，避免重复扣除资源。

退出到首页后，后台仍会继续生成；想暂停时先点「停止生成」。关闭整个应用后，未完成的回复不会自动继续。

## 行动未送达时

如果提示有行动未送达，选择「重试提交」，或点击「放弃该批次」后重新声明行动。处理前仍可用聊天讨论，但不能提交新行动。

“已接收”只表示主持收到了行动，不代表已经裁定。如果主持收到行动后回复失败，先检查已有结果，再发新消息继续。

## 调整主持的叙事方式

在「冒险设置 → 模型与主持 → 主持系统提示词」点击「编辑」，可以调整这局的叙事口吻和裁定要求，例如：

> 描述环境时先交代角色能感知到的细节。遇到危险先说明可见风险，等我声明行动后再处理结果。

修改从下一次主持回复起生效，也可以恢复内置指令。新冒险的默认指令在「设置 → 冒险默认设置 → 进阶」中调整，不影响已有冒险。

## 查看推理与执行细节

想了解 AI 做了什么，可以在「冒险设置 → 显示与调试」开启「显示推理细节」，再展开消息中的「推理与执行细节」。这些内容可能包含幕后资料，正常游玩可保持关闭。

「冒险设置 → 会话状态」还可查看主持和队友的上下文、用量与费用。对话较长时会自动压缩早期记忆；需要提前整理时，选择对应角色并点击「手动压缩」，不会推进剧情或删除聊天记录。一般无需修改自动压缩阈值。

## 上下文订阅

主持默认按需查阅资料。想让 AI 持续关注生命、资源等状态，可以在「冒险设置 → 对话与上下文 → 上下文订阅」开启「允许 AI 订阅文档字段」。AI 会自行选择关注的字段，每轮读取最新值。

订阅默认关闭。开启后可能减少查阅次数，也会增加上下文用量。队友使用订阅还需开启[文档查阅](companions.md#允许队友查阅文档)。不确定是否需要时，保留默认设置即可。
