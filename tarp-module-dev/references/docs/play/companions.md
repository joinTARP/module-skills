# AI 队友

AI 队友就像一起跑团的玩家，会讨论计划、提出自己角色的行动，再等主持裁定。每名队友有独立的记忆，也可以使用不同的模型。

## 开局时选择队友

确认自己的角色后，如果模组提供可用同伴，聊天中会出现队友选择卡。选择同伴并开始冒险，或点击「独自开始」。没有可用同伴时，应用直接开场。

完整步骤见[第一次冒险](../getting-started/first-adventure.md#决定是否和队友一起开场)。

## 查看当前小队

游戏左侧「冒险小队」显示你和已入队的角色。点击成员查看角色卡，右键其他成员可以点名。

## 游戏中添加一名队友

1. 打开「冒险设置 → 冒险小队」。
2. 点击「空位」，选择角色；出现待确认卡片时，点击「入队」。
3. 确认队友已经加入小队，再关闭设置继续冒险。

角色需要在当前开局的可选名单中，有模组提供的 AI 扮演指引，并且还没被占用。没有候选时，先看页面提示；不能直接把任意 NPC 交给 AI。

正在生成回复时，先停止生成，再添加或移除队友。点击队友卡片右上角的按钮，可以把它移出小队；重新添加不会自动恢复它原来的记忆。

修改源模组的队友预设后，要[同步模组](../getting-started/first-adventure.md#同步已有冒险的模组)或新建冒险才能采用。

## 想听它的意见，直接点名

在输入框中输入 `@`，从候选里选择队友，再写下问题：

> @阿青 你觉得我们该先问店主，还是去仓库看看？

单纯手打 `@名字` 不会点名。正在生成时，新点名会排队回应。

带点名的消息始终作为聊天发送，不交给主持裁定。想让主持处理实际行动，另发一条不带点名的行动；询问规则或澄清描述，可以[点名主持人](ai-host.md#和主持人聊天)。

队友可以先聊天，再提出自己的行动。手动提交时，它的行动和你的行动都要等点击「继续」后才交给主持；想让它改变计划，可以先点名讨论。具体见[提交方式](ai-host.md#先讨论再点继续)。

队友可以跨场景讨论，但不会因此移动或获得角色尚不知道的信息。希望同行、分队或让它留下时，用行动告诉主持。新加入的队友不知道此前的完整经过，必要时先向它介绍情况。

连续点名交流默认最多回应 8 条，达到上限后会停止并显示提示；可在「冒险设置 → 冒险小队 → 连续响应上限」调整为 1–32 条。

## 调整它多久开口

打开队友卡片的「设置 → 互动」，调整「互动主动性」并保存：

| 档位         | 发言习惯                                     |
| ------------ | -------------------------------------------- |
| 克制         | 主要在被交谈、遇险或轮到自己时回应。         |
| 自然（默认） | 与场面有关时参与，没有新内容就保持沉默。     |
| 积极         | 你行动后，判断是否补充准备、提醒或配合行动。 |
| 活跃         | 主动推动冒险，裁定后也可能继续行动。         |
| 自定义       | 自己填写参与讨论和行动的时机。               |

积极和活跃的队友可能在主持裁定前补充行动。选择自动提交时，会等队友判断后再一起交给主持裁定。活跃队友还可能连续推进行动，想暂停时点击「停止生成」。

队友判断要不要发言时也会调用模型，即使最后没有开口。想控制用量，可以减少队友数量或调低主动性。

想调整所有队友的表达风格，可以在「冒险设置 → 冒险小队 → 队友扮演指导」编辑，例如要求讨论时少说空话、有具体风险再提醒。修改不会改变角色设定，也不会让队友获得裁定权限。

## 允许队友查阅文档

在队友的「设置 → 互动」中打开「允许队友查阅文档」。默认关闭，开启后它可以按需查阅玩家可见的规则、角色、物品和线索，不能查看隐藏资料或修改世界状态。

查阅可能增加等待时间与模型用量。需要它持续关注某些状态时，还可开启[上下文订阅](ai-host.md#上下文订阅)。

## 新增队友默认模板

在「冒险设置 → 冒险小队 → 新增队友默认模板」中，可以为之后加入的队友设置模型、主动性、文档查阅和备用声音。修改模板不会影响已经加入的队友。

新冒险的模板在「设置 → 冒险默认设置 → 队友」中配置。

## 分别选择模型和声音

队友卡片的「设置 → 模型」可以单独选模型，也可选择「跟随冒险模型」。新队友会先使用这局模板中的设置，修改模型从它下次发言起生效。

在「设置 → 声音」中可以调整这名队友的朗读音色，操作见[语音朗读](voice.md)。

## 为什么它没回应

没有新内容时，队友可以保持沉默。想听它回答，就从 `@` 候选中点名它。

仍没回应时，检查它是否还在小队中、模型连接是否可用，以及是否达到连续响应上限。需要排查时，可开启[推理与执行细节](ai-host.md#查看推理与执行细节)。

点击「停止生成」会停止当前回复，并取消排队中的回应。退出到首页后，后台仍会继续生成，想暂停时先停止；关闭整个应用后，未完成的回应不会自动继续。如果提示行动未送达，按[未送达行动的处理方法](ai-host.md#行动未送达时)操作。
