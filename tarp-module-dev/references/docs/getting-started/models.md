# 连接模型服务

[启动桌面应用](introduction.md#安装并打开应用)后，在「设置 → 模型配置」中登录服务商或保存连接，再到「设置 → 冒险默认设置 → 常规」选择默认主持模型。

每个服务商保存一套连接，多段冒险可以共用；再次设置同一服务商时，会更新已有连接。默认模型只用于之后创建的冒险，已有冒险保留自己的选择。其他新冒险初始设置见[冒险默认设置](game-defaults.md)。断开服务后，已保存的模型选择仍保留，但需要重新连接或更换模型才能使用。

## 使用订阅登录

当前界面提供 ChatGPT 订阅登录，使用账号可用的 Codex 模型和额度，无需填写 API Key。

1. 在「服务商」一栏找到 ChatGPT，点击「登录」。
2. 点击「使用 ChatGPT 登录」，在打开的浏览器中完成登录。
3. 回到应用，等状态变为「已连接 ChatGPT 账号」。
4. 打开「冒险默认设置 → 常规」，在「默认主持模型」一栏点击「选择模型」。

浏览器登录后没有自动返回时，展开弹窗里的「浏览器登录后没有自动返回？」，粘贴浏览器最后跳转的完整回调地址，再点击「完成登录」。

也可以选择「设备码登录」，按弹窗提示在浏览器中输入设备码。不要把设备码、回调地址或登录凭据发给别人。

登录成功后，模型选择器会显示订阅连接可选的模型；实际调用权限和额度由你的账号决定。

## 使用 API Key

如果你已有模型服务的 API Key：

1. 点击「连接服务商」，搜索并选择对应服务商。
2. 粘贴该服务的 API Key，点击「保存配置」。
3. 打开「冒险默认设置 → 常规」，在「默认主持模型」一栏点击「选择模型」。

修改已保存的连接时，点击它右侧的「管理」。在同一个连接中，API Key 输入框留空会保留原密钥。

桌面应用不会自动使用终端或系统环境变量中的密钥，也不会自动发现其他工具的认证文件。请在应用内连接服务商。点击连接右侧的「断开」后，该连接的模型会从可选列表中移除；需要使用时重新连接。断开自定义服务还会删除该服务的模型定义，重新连接时需要重新填写接口和模型信息。

模型列表来自 pi 的服务商目录，不会逐一验证你的账户是否有调用权限。界面显示「已连接」表示连接信息已保存，能否实际调用，还取决于密钥、账户权限、额度和网络。进入冒险后，让主持完成一次回复，可以确认连接是否可用。

## 使用自定义兼容接口

列表里没有你的服务，或需要连接本机提供的服务时，可以点击「连接服务商 → 自定义服务」。选择服务支持的接口协议，再填写连接信息：

| 字段      | 填什么                                                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------------------------- |
| 服务商 ID | 以小写字母或数字开头，后续使用小写字母、数字和连字符，例如 `my-service`。同一个 ID 对应一套连接，不能与内置服务商重复。 |
| 接口协议  | 按服务说明选择 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 或 Google Generative AI。                  |
| 服务地址  | 服务提供的 HTTP(S) 接口基础地址，例如 `https://example.com/v1`；不要填写网页控制台地址。                                |
| 模型 ID   | 服务接受的准确模型标识，按它的说明填写。                                                                                |
| API Key   | 这个接口使用的密钥；当前表单要求填写。                                                                                  |

`https://example.com/v1` 只是格式示例，需要换成你自己的地址。保存后，打开「冒险默认设置 → 常规」的模型选择器，选中这条自定义连接的模型。已有冒险的选择方法见下节。

主持需要读取资料、掷骰和更新文档，因此接口除了能返回文字，还需要支持模型的工具调用。只支持普通聊天的接口可能无法完成一轮冒险。连接本机服务时，也要确认它支持当前兼容接口的请求方式和工具调用。

同一服务商 ID 共用接口协议、地址与凭据，可以保存多个模型 ID。管理已有连接时填写新的模型 ID，会增加该模型并保留原有模型；修改接口地址或协议则影响这个服务商下的所有模型。需要同时连接不同端点时，使用不同服务商 ID。

更换自定义接口地址时，需要重新填写新地址对应的密钥；应用不会沿用旧地址的密钥。地址不能包含账号或密码。

## 设置推理强度

在模型选择器中先选择「推理强度」，再点击模型保存；调整当前模型时，重新点击同一个模型即可。应用默认主持模型、默认队友模型、当前冒险模型和队友单独模型均可设置，跟随冒险模型的队友也跟随其推理强度。

可选默认（中）、关闭、最低、低、中、高、超高和最高。实际强度由模型支持范围决定；不支持的档位由模型运行时调整，不支持推理的模型会忽略此设置。更高强度可能增加等待时间与用量。自定义兼容接口需要在连接配置中勾选「此模型支持推理」，并确认服务端支持推理参数。

当前冒险的调整从下一次 AI 回复起生效；应用默认设置仅影响之后创建的冒险。「显示推理细节」只控制记录展示，不改变推理强度。

## 更换当前冒险的模型

进入冒险，打开「冒险设置 → 模型与主持 → AI 模型」，点击「选择模型」或「更换模型」。选中后，从下一次 AI 回复起使用新模型，其他冒险不受影响。

如果你先创建了冒险、后来才设置默认模型，也需要在这个冒险里选一次。默认模型不会自动应用到已有冒险。

AI 队友可以跟随冒险模型，也可以单独选择。队友的模型设置见[AI 队友](../play/companions.md#分别选择模型和声音)。语音使用另一套服务配置，见[语音朗读](../play/voice.md)。

## 没有回复时先看什么

- **模型列表为空**：检查服务商是否完成登录或保存密钥，再打开模型选择器。
- **当前冒险提示未选择模型**：到「冒险设置 → 模型与主持 → AI 模型」选择，单改默认模型不会影响它。
- **提示连接不可用**：检查原连接是否被断开、订阅是否退出，重新登录或选择仍可用的连接。
- **调用报错**：根据错误检查密钥、模型 ID、服务地址、账户额度和网络。兼容服务还要确认工具调用支持。
- **消息发出后没有调用 AI**：检查是否使用了无点名的「聊天」模式，或指令正处于「手动提交」；后者需要点击「继续」。

连接完成后，按[第一次冒险](first-adventure.md)发送一条行动。主持完成回复，才说明当前模型能够处理这一局。调用费用与资料发送范围见[常见问题](../reference/faq.md)。
