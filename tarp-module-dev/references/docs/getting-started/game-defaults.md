# 冒险默认设置

打开应用「设置 → 冒险默认设置」，通过「常规」「语音」「队友」「进阶」四个页签设置新冒险的初始配置。

创建冒险时，应用会复制这些配置。以后修改默认值，只影响新建的冒险；已有冒险保留自己的配置，可以在「冒险设置」中单独调整。

## 可以设置什么

- **常规**：默认主持模型、自动或手动提交、主持插话、连续点名响应上限，以及推理细节和全部模组内容的显示开关。显示选项可能剧透；模型服务连接在[模型配置](models.md)中管理。
- **语音**：允许语音、自动朗读、供应商、模型、音色与讲述风格。关闭语音后收起声音配置，原值继续保留；点击「编辑」可以修改讲述风格。连接与播放见[语音朗读](../play/voice.md)。
- **队友**：新增队友的默认模型策略、互动主动性、文档查阅开关和兜底声音。选择「自定义」主动性后，可编辑自定义互动指令；切回预设档位会保留文本。加入后的个人设置见[AI 队友](../play/companions.md)。 还可编辑所有队友共用的扮演指导，或恢复内置指导；具体见[AI 队友](../play/companions.md)。
- **进阶**：通用主持指令、自动压缩阈值和[上下文订阅](../play/ai-host.md#上下文订阅)。订阅允许 AI 自行选择每轮附带的文档字段，会增加 Token 消耗，但可能减少读取请求。主持指令先显示「使用内置指令」或「已自定义」，点击「编辑」查看和修改正文；主持和 AI 队友分别设置压缩阈值，留空按当前模型窗口自动计算。

出厂设置使用自动提交，允许语音，自动计算压缩阈值；主持插话、上下文订阅、自动朗读和调试显示选项默认关闭。队友的互动主动性为「自然」，模型默认跟随当前冒险的主持模型，文档查阅默认关闭；连续点名响应上限默认 8 条，可设为 1–32。

## 保存与生效

开关和选择项修改后立即保存。文本和数值在完成输入、离开输入框或确认时保存；多行文本也可以按 ⌘ / Ctrl + Enter 确认。切换页签、关闭文本编辑器、切换设置分类或返回应用前会提交修改，保存失败时保留输入并显示重试入口，修正或重试成功后才能离开。页头显示「已保存」「待保存」「正在保存」或「保存失败」。

创建冒险时会保存主持指令和队友扮演指导的正文，之后修改应用默认值或更新内置提示词不会改变已有冒险。冒险内修改从对应角色的下一次调用开始生效；队友扮演指导影响本局所有队友。

队友模板也在创建时保存，之后加入的队友使用本局模板。修改本局模板只影响新加入的队友，已加入的队友保留各自设置。

## 服务连接与冒险配置

模型和语音供应商连接由应用集中管理，可供多段冒险共用；冒险只保存选用的供应商、模型和参数，不保存密钥。

服务不可用时仍可创建冒险，已选配置会保留。需要使用相关模型或语音时，先重新连接服务，或在该冒险中更换选择。删除连接不会自动把已有冒险切换到其他服务。
